# Security policy

`rtl-text` only rewrites the text of transcript messages as they are drawn. It
makes no network requests, reads and writes no files, runs no processes, and
stores one value: whether `/rtl` is on.

If you find a security problem, please don't open a public issue. Report it
privately through
[GitHub's private vulnerability reporting](https://github.com/smhosseini72/claude-code-rtl/security/advisories/new).
